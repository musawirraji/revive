# Revive Design & Renovation — AI Renovation Estimator

A single-page Next.js demo that walks homeowners through a six-step questionnaire and returns an instant ballpark renovation estimate generated by the Anthropic Claude API.

Built for a Tampa / Orlando, FL premium remodeling company.

## Quick start

```bash
# 1. Install dependencies
npm install

# 2. Add your Anthropic API key
cp .env.local.example .env.local
# then edit .env.local and paste in your key

# 3. Run the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment

Add this to `.env.local`:

```
ANTHROPIC_API_KEY=sk-ant-...
```

## Project structure

```
app/
  layout.js           Root layout, fonts (Inter + Fraunces), metadata
  page.js             Single-page step flow + results screen
  globals.css         Tailwind + custom animations and tokens
  api/
    estimate/
      route.js        Server-side Claude API call (claude-sonnet-4-20250514)
tailwind.config.js
postcss.config.js
next.config.mjs
```

Everything client-facing lives in `app/page.js`. The Anthropic call lives in `app/api/estimate/route.js` so the API key is never exposed to the browser.

## Deploy to Vercel

1. Push the project to a GitHub repo.
2. Import the repo at [vercel.com/new](https://vercel.com/new).
3. Add the `ANTHROPIC_API_KEY` environment variable in the project settings.
4. Deploy.

That's it.

## Design notes

- Typography pairs **Fraunces** (serif, upright only) for editorial headlines with **Inter** for UI and body.
- Color palette: warm off-white background (`#FAF8F3`), warm ink (`#1A1714`), brand blue accent (`#0171BB`).
- All step transitions use a subtle horizontal fade-translate (no large slides or bounces).
- The results screen reveals sequentially: range → financing → summary → timeline → CTA → disclaimer.

## Customizing copy

All step questions, descriptions, and feature options are defined as plain objects at the top of `app/page.js`. Edit them in place — no schema or config file to chase down.
